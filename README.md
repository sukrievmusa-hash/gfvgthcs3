# Nur Aspan — сайт натяжных потолков (Тараз)

Демо: https://sukrievmusa-hash.github.io/gfvgthcs3/

Статичный сайт на HTML, CSS и JS, без сервера. Подходит для GitHub Pages.

## Что внутри
- **index.html** — лендинг на русском и казахском (RU/KZ), язык запоминается.
- **Калькулятор цены**: площадь, комнаты, полотно, профиль, светильники, люстры, световые линии. Расчёт уходит в WhatsApp одним нажатием.
- **Каталог из 8 типов потолков**: у каждого есть кнопка «Хочу такой», которая открывает WhatsApp с готовым текстом.
- **Заявка на замер**: форма отправляется в WhatsApp.
- **Филиалы** с маршрутами в 2ГИС и Яндекс Картах, а также FAQ и SEO-разметка (schema.org с двумя филиалами).
- **otzyv.html** — оценка бригады после монтажа: срок, качество, чистота, вежливость. Оценка уходит руководителю в WhatsApp, после этого клиенту предлагается оставить отзыв в 2ГИС.
- **qr/** — QR-коды на страницу оценки: общий и для бригад 1–3. Их можно распечатать и выдавать монтажникам.

## Что заменить перед запуском (всё в начале `app.js`, объект `CONFIG`)
1. `prices`: сейчас стоят **ориентировочные** цены по рынку Тараза. Их нужно заменить на прайс Nur Aspan.
2. `rateWa`: личный WhatsApp руководителя, чтобы оценки бригад не попадали в общий чат.
3. `works`: настоящие фото работ. Положите их в `img/` и перечислите в массиве. Пока вместо фото стоят иллюстрации.
4. Проверить ссылки на Facebook и 2ГИС, если у компании есть точные ссылки на карточки.
